## Локальная проверка

Откройте `index.html` в браузере.

## GitHub Pages

1. Создайте публичный GitHub-репозиторий.
2. Добавьте его как remote для этой папки.
3. Запушьте ветку `main`.
4. В настройках репозитория включите Pages: `Settings -> Pages -> Deploy from a branch -> main -> /root`.
